Alpha · Onboarding

Get started with Amplitude Opportunities.

Amplitude Opportunities helps product and engineering teams proactively analyze signals across your Amplitude data, identify clear problems to fix or opportunities to grow, generate specs for humans or coding agents to work on, and measure whether what shipped actually moved the metric.

Private alpha · v0.4 · last updated 2026-05-27

§Intro

Opportunities are identified by unifying insights across analytics, session replays, customer feedback, web vitals, agent traces, experiments, and competitor data, then using agents to analyze it all and explore improvement ideas. The more data sources and agents in your Amplitude instance, the more context the agent has to identify high-value opportunities.

From the Amplitude UI you can route opportunities into your issue tracker, or connect GitHub, Claude, Cursor, or another coding tool to have coding agents pre-draft PRs for your review before shipping.

If you don't want to use the Amplitude UI at all, you can read and edit every Opportunity via Amplitude's MCP server — pull context directly into Claude Code, Codex, and Cursor to auto-triage opportunities and orchestrate coding agents to draft PRs autonomously.

§What to expect

By the end of onboarding you should be able to:

  • Create an initial set of Product Areas
  • Generate and view Opportunities
  • Connect the workflows you want to use for execution
  • Connect the Opportunities MCP tools in your preferred AI client
  • Review an initial batch of Opportunities and leave feedback
  • Take action on at least one high-confidence item
Heads up

This alpha is designed to help you find valuable problems faster. It is not a fully autonomous workflow yet — start with review, validation, and one small action.

01Create your first Product Areas

Product Areas tell the agent where to focus and let you customize how it identifies, prioritizes, and specs opportunities for that surface.

For each Product Area, define:

  • A concise name
  • A brief description of what it is and its top strategic objectives
  • Optional — the key metrics or goals you care about
  • Optional — competitors or comparables you want to monitor

When you open Opportunities for the first time (or visit "all product areas"), you can use the setup agent to chat your way through, or create areas manually.

Recommendation

Start narrow. 2–3 well-defined areas will outperform 10 vague ones every time.

02Connect the context that matters

Opportunities work best with more Amplitude data wired in. You don't need every source on day one — the more relevant signal, the sharper the agent.

  • Product Analytics (existing charts and dashboards)
  • Session Replay
  • AI Feedback
  • Autocapture
  • Agent Analytics
  • Experiments

Context from existing Specialized Agents in your org also flows in — insights from Dashboard, Session Replay, Customer Feedback, and other agents are more likely to surface as signals driving new recs.

Highest-leverage source

Your codebase. If your org is open to it, give our team a heads up and we can connect a few GitHub repos so recommendations reflect the current state of the product and where a change should land.

03Choose how you want to take action

Two common modes. Pick whichever fits how your team already works — you can use both.

In-app UI

Review opportunities in Amplitude, then use the in-product CTAs to push to Jira, Linear, GitHub, or a coding agent.

Agent-native MCP

Use MCP in Claude Code, Codex, Cursor, or another client to read, edit, triage, and act on opportunities directly from your editor.

04Generate and review your first batch

Once your Product Areas and connections are set, generate your first batch. Click Discover any time you want to refresh.

As you review, ask three questions:

Q1
Is the analysis or signal correct?
Q2
Is this a reasonable problem to work on?
Q3
Is the suggested plan useful?

Use the thumbs up / thumbs down control on each opportunity. Every labeled input feeds your team's preferences back into the ranker — the next batch gets sharper automatically.

05Take one real action

The fastest way to feel value is to pick one small, high-confidence opportunity and move it forward.

  • Send it to Jira or Linear
  • Open it in Claude Code, Cursor, or another coding tool
  • Refine it through Global Chat or MCP before handing it to a coding agent
  • Validate it internally and decide next steps with engineering

If the analysis or recommendation isn't quite right, you can edit the plan directly or chat with Global Agent to run follow-up analysis and revise the spec before any action ships.

→Suggested next step

Once setup is done, start with a small first batch, choose one high-confidence opportunity, and work it through your normal execution flow. That's the fastest path to value — and the fastest way to improve quality from there.
