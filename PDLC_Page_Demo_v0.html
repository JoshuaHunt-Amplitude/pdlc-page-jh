The manifesto

Sense is the new bottleneck.

The product development loop has always been the same: build → ship → use → learn. Fifty years of work — programming languages, agile, cloud, and now coding agents — collapsed the left half. The distance from problem identified to code shipped is approaching zero.

The right half hasn't moved. Humans still triage Slack threads, watch session replays, read error logs, interpret experiments, and try to synthesize all of it into "what should I build next?" For every issue that survives that gauntlet, hundreds don't.

Analytics, for a decade, has been an insight factory. "Here's what happened" charts. Dashboards no one opens. Anomalies no one routes. More than 95% of behavioral data goes unread. That isn't an analytics problem. It's a sensing problem.

The teams that have mastered this — Anthropic, OpenAI, Meta, Netflix, Stripe — run it manually, with proprietary tooling. Stripe ships 1,300+ PRs/week from internal coding agents. Ramp's Inspect authors 57% of merged PRs. The asymmetry between ship and sense is the gap they're closing one custom system at a time.

PDLC is the version any team can run. An agent-native loop wired into the data layer that already knows what matters to your users — anomalies, replays, feedback, experiments, agent traces. It senses, prioritizes, specs, ships, verifies, and learns. Every cycle compounds the next.

The next era of analytics is a closed loop.

Loop 02 · Detect

Not every problem
throws an exception.

A 12% drop in day-7 retention isn't an error — it's a signal. The detection loop watches what users actually do: where they hesitate, what they skip, which funnels they abandon, what they rage-click. It surfaces anomalies before they compound.

Human judgment enters at triage. Everything before — collection, anomaly detection, theming, routing — is automated.

Loop 03 · Decide

Where humans
make the call.

The outermost loop is where strategy lives. Usage patterns surface opportunities — features users wish existed, journeys that feel broken, segments quietly churning. The machine proposes. The team decides. Data validates who was right.

Then the loop repeats — tighter and smarter each cycle, because every outcome is labeled training data for the next round.

The compound effect

Every loop
feeds the next.

Heal stabilizes the product — freeing human attention for higher-order work. Detect surfaces what to improve. Decide chooses what gets built. Every output feeds back into the data core. Each loop gets faster and more autonomous over time.

Cut any one and the system stops. Without Heal, your product breaks in silence. Without Decide, your product gets better at the wrong thing.

The flywheel never stops. It just gets better at spinning.

Three surfaces

However your team already works.

Same loop. Same data. Same opportunities. Three places to meet you where you are — inside Amplitude, inside your coding agent, inside your terminal.

hubMCP

For every coding agent.

The primary surface. Every Cursor, Claude Code, Codex, or custom harness can ask Amplitude "what should I work on?" and get a ranked list with full evidence — chart IDs, replay IDs, feedback IDs. Source-cited context so the agent grounds its work.

# Cursor / Claude Code
→ amplitude.opportunities(
    area: "chart-creation",
    limit: 5
  )
terminalCLI

For the developer loop.

The same opportunities as MCP, shell-shaped. Query the queue from a terminal without a UI. Where MCP fits inside an agent loop, the CLI fits inside a developer's loop — between commits, between context switches.

$ amp opportunities list \
    --area chart-creation \
    --limit 10

# → ranked spec output
